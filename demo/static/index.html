真实可解性验证 — 无损 codec 图像 ⇄ .bin 文件

⚠ ImageNet64 模式：64×64 编/解各 ~12500 步，单向约 4–8 分钟（CIFAR 的 ~4×）。.bin 容器记录图像几何，只能用同款 IN64 模型解码（CIFAR↔IN64 互解会被几何校验拒绝）。

把模型当真实无损 codec：上传图 → 逐 token gold 算术编码下载真实自包含 .bin（MDLC 容器，与 CLI verify_lossless.py --dump_dir 逐字节一致）；再把 .bin 传回 → 仅凭文件即时解析结构， 或逐 token 盲解码还原图像、逐像素比对。编/解同一逐 token 路径 → bit-exact 可解（指纹一致即证）。 解码无 KV-cache → 每 token 一次完整 forward，CIFAR ≈ 3100 步、约 1–2 分钟，流式进度条实时显示（绕开反代超时）。
