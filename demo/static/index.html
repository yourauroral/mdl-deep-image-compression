Linear Probe 各层分类准确率

OOD 检测 — typicality（密度估计侧面）

把 CIFAR-10 训练的 CC-iGPT 当密度模型，用 per-image bpd 偏离做异常分，AUROC 衡量识别分布外的能力。 raw bpd 复现 Nalisnick 2019 失败（CIFAR 训的模型给 SVHN 更低 bpd，AUROC 常 < 0.5）； typicality |z| 修正之；dual-scale（sqrt(zcoarse²+zfine²)）是本工作双尺度差异化，单尺度模型给不出。 虚线 0.5 = 随机基线。

图像补全 — AR inpainting（生成侧面）

给前 keep% 比例的 raster token（≈上半若干行），AR 续采样补全其余（Sparse Transformer 同款定性下游，AR 模型天然支持、不重训）。 诚实声明：CC-iGPT 的 coarse ctx 由整图缩略图算 → 语义是"低分缩略图 + 上半真实像素 → 补下半"，coarse 是显式 side-channel（与压缩时独立 bitstream 同源），非偷看答案。
